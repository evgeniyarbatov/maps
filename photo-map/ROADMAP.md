# Roadmap

## Why keep going

This is the spatial index for every other photo repo — [private],
[private][private]
none of which currently let you ask "what did I see near here." A local map
you already trust is worth more than another catalog script, because it's
the piece none of the others can substitute for.

## What it opens up

Once photo-map is the canonical geotagged index, cross-repo questions become
possible that no single repo can answer alone: photos taken within 200m of
any GPX route you've run (bridging to the gpx-* / [private]
cluster), or photos near streets that were renamed ([private]).

## Capability this builds

A small local web app as a personal data browser — a pattern worth reusing
for any other geotagged or timestamped personal dataset, not just photos.
